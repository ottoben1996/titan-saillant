# Médias d’exercice — décision du 5 septembre 2026

## Intégré dans l’application

- 27 illustrations WebP locales issues du jeu gratuit RepDB, soit environ 503 Ko au total.
- Elles couvrent 16 mouvements du programme avec une image unique (maintien/cardio) ou les poses « départ » et « fin ».
- Elles sont uniquement un repère visuel : les consignes françaises de l’application restent la référence de la séance.
- Attribution visible : `Exercise data by RepDB (repdb.co)` dans les réglages et sous chaque tutoriel illustré.

Licence vérifiée : le jeu gratuit RepDB autorise l’usage personnel et commercial **dans une application** avec attribution visible. Il ne peut pas être redistribué sous forme de base de données ou d’API.

## Écarté

- GIF/vidéos réhébergés sans droits explicites : pas intégrés.
- Dumps ExerciseDB / GymVisual : usage commercial non autorisé ou licence propriétaire à acquérir.
- Animations WebGL continues : trop coûteuses pour une PWA utilisée en salle.

## Sources évaluées

- RepDB : source retenue pour les illustrations légères et locales.
- Lightswind : licence MIT confirmée ; ses modèles Drawer, Progress et Toast confortent l’interface actuelle, déjà construite sans dépendance réseau. Une migration vers ses sources n’est pas justifiée tant que le gain fonctionnel est nul.
- OriginKit : un seul effet décoratif léger pourrait être testé plus tard, mais aucune licence publique complète par composant n’a été confirmée. Aucun code OriginKit n’est embarqué à ce stade.
- Pour une future couverture vidéo complète de toutes les machines : acheter une collection explicitement commerciale, puis intégrer uniquement les MP4/WebM utiles et les précacher.
